Projeto desenvolvido para a atividade prática.

Criado um Banco de Dados teste no PostgreSQL para que a API conseguisse buscar os dados.

A ideia principal foi apenas além de fazer GET, fazer consultas com filtros, já também tentando organizar a estrutura do projeto da melhor forma possível.

```bash
pip install -r requirements.txt
```

```bash
uvicorn app.main:app --reload
```
